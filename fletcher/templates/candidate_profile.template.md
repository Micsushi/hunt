# Candidate Profile Template

Copy this file to `fletcher/candidate_profile.md`, which is gitignored, and add
only reviewed candidate facts. C2 uses it for approved context beyond the
source resume.

## Rules

- Never invent metrics, tools, dates, employers, education, authorization, or
  personal claims.
- Leave unknown fields blank.
- Replace every angle-bracket marker before using the profile.
- Entry IDs must match the slugs reported by `fletch context`.
- Each bullet must cite one or more immutable fact IDs.
