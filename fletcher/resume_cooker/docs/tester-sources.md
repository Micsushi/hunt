The digest is SHA-256 over every sorted Git-tracked or non-ignored snapshot path using
`path + NUL + byte-length + NUL + file-bytes + NUL`. It was recomputed on 2026-07-27 after the
security patches below. Any snapshot change must update its digest, file count, and patch record in
the same change.

## Local Patch Record

- `ATS-Checker`: excluded generated bytecode; replaced client-controlled upload paths with
  in-memory parsing; bounded requests; disabled debug mode; migrated to `pypdf`; added tests and a
  fully pinned, hash-locked, audited Python dependency set.
- `ats-screener`: retained the copied keyword-matcher change and local scoring entry point; refreshed
  the JavaScript lock and vulnerable framework/tool dependencies; added explicit safe transitive
  overrides; aligned the Vite/Vitest configuration types.
- `Resume-Matcher`: refreshed the frontend lock, Next.js, sanitizer dependencies, and vulnerable
  transitive overrides; normalized existing Prettier violations; installed deterministic jsdom
  storage for Node 25 tests. The Resume Cooker adapter remains explicitly deferred.
- `ResumeParser`: no local source patch; Resume Cooker invokes it only through the bounded structural
  probe when an isolated environment is supplied by the caller.

## Excluded From Snapshots

The copies intentionally exclude:

- Nested `.git` directories
- Python virtual environments
- `node_modules`
- Python bytecode and `__pycache__`
- Build and cache output

This keeps Resume Cooker version-controllable while preserving the tester source and local useful changes.
