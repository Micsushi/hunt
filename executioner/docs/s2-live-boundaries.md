# C3 v3 Stage 2 live boundaries

This is the human authority record for S2-F0-T1. It applies only to descendants
of accepted Stage 1 commit `87c77e538d8bba378ec93516dbea3f4747beb822`.
It defines policy and ownership, not TypeScript shapes or provider behavior.

The three storage roots are `runtime`, `secrets`, and `evidence`. All are
outside the repository and accessible only to the current Windows user. The
named runtime operator, secret custodian, and evidence custodian are the same
local human owner acting in distinct roles.

F9 owns the only journey loop, retry budget, cancellation flow, live-result
classification, and terminal projection. The existing MCP facade is the only
public facade. Providers own their observations and effects; they never emit a
terminal or MCP envelope. F9 never resolves plaintext credentials or raw
verification links.

Unknown or ambiguous live input stops at the layer that observed it. Runtime
code may retain only sanitized structural trait IDs, counts, reviewed IDs, and
exact factual outcomes. It cannot mutate or reload selectors, page signatures,
question catalogs, option aliases, applicant facts, or answers. S2 and S3 are
Workday-only; every non-Workday family returns `ats_unsupported`.

## Change rule

Later feature owners cannot edit this boundary locally. A provider mismatch,
new live consumer, new retained value, different wire shape, broader learning
policy, or common contract change outside the explicit F0 delta reopens F0.
