# Console colors

The shared colors live in `frontend/src/styles/tokens.css`. Use the same roles across Overview, Hunter and Fletcher.

- Use the darkest surface for the page, forest green for navigation, and the lighter panel colors to group related work.
- Use off-white for names and values, and muted sage for labels and secondary details.
- Use the bright green accent for primary actions and links. A selected navigation item has a pale green background and dark text.
- Pair status colors with a readable label. Reserve amber for warnings and red for errors or destructive actions.
- Keep document previews paper-colored. Review annotations and charts may use additional colors to distinguish data.
